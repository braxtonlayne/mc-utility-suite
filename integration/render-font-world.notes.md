# render-font-world: integration notes

Branch work: (A) the suite font pipeline without any download, (B) the world drawing kit (`IHoloWorld`) and its
first adopter, Ghost Line. stem-ui design sections 4, 5.3, 5.4, 8.12, 9.

## A. Suite font pipeline (`ui/holo/SuiteFonts`)

### Mechanism (checked against the mapped NeoForge 21.1.265 sources)

- A font definition JSON whose `ttf` provider names a missing file makes `FontManager.safeLoad` log
  `Failed to load builder ..., rejecting` with a stack trace on every reload, and the whole font id then fails to
  resolve (`UnresolvedBuilderBundle.resolve` returns empty). So **no definition JSON is shipped as a file**.
- `SuiteFonts.Client` listens to `AddPackFindersEvent` (mod bus, `CLIENT_RESOURCES`). It checks the mod's own file
  (`ModList...getModFileById("utilitysuite").getFile().findResource("assets", "utilitysuite", "font", name)`) for
  the three TTFs. Only when all three are there it adds a hidden, required, in-memory pack (`DefinitionPack`,
  a plain `PackResources`) that serves `utilitysuite:font/ui.json`, `micro.json`, `mono.json`, generated by
  `SuiteFonts.definitionJson`: `[{ttf, file, size, oversample, shift, filter: {uniform: false}},
  {reference: minecraft:default}]`. Without the files the pack is never added: the font manager never hears of the
  suite ids, nothing is logged at error/warn level (one INFO line says the files are absent).
- Vanilla then loads the faces: FreeType rasteriser, vanilla glyph atlases (`FontSet`/`FontTexture`), vanilla
  batching. Missing characters fall back to `minecraft:default` through the reference provider. The `uniform: false`
  filter switches the TTF off inside vanilla too when Force Unicode Font is on.
- Drawing: `HoloKit` draws with the game's own `mc.font`, passing one reusable `FormattedCharSequence`
  (`SuiteFonts.Client.Run`, decoded with `StringDecomposer.iterateFormatted` exactly like a plain String) whose
  `Style` carries the suite font id (`Style.EMPTY.withFont(utilitysuite:ui|micro|mono)`, created once per face).
  `Font.getFontSet(style.getFont())` resolves it through the font manager. **No access transformer, no mixin** (the
  design's AT on `Font.fonts` is not needed; `META-INF/accesstransformer.cfg` was not created).
- Widths: `HoloKit.width/numberWidth` measure through the same `Font` and the same style that draw. Tabular digit
  widths are cached per role and dropped when `SuiteFonts.generation()` changes.
- Fallbacks (all to the plain vanilla path, which is byte-for-byte today's code path): files absent; appearance
  setting `font = VANILLA`; Force Unicode Font on (sampled once per HUD frame in `HoloKit.begin`, logged once);
  load failure (probe on the first HUD frame after a reload: a failed face resolves to vanilla's "missing" set,
  where 'i' and 'W' have the same advance; logged once at WARN).
- A reload listener (`RegisterClientReloadListenersEvent`) re-checks the TTFs through the `ResourceManager` after
  every reload.

### Appearance settings (`VisualSettings`)

- `font`: `SUITE` (default) / `VANILLA`, writes `HoloTheme.suiteFont`.
- `armed_marker`: bool, default false, writes `HoloTheme.armedMarker` (another task draws it).
- Appended after `hud_scale` (indices 5 and 6), so the existing indices are unchanged. `VisualSettingsTest` covers
  defaults, round trip and unknown values. Lang keys: `integration/render-font-world.lang.json`.

## B. World kit (`ui/holo/HoloWorldKit`) and Ghost Line

- `HoloWorldKit implements IHoloWorld`: ribbon, polyline (solid or dashed), ring (32 segments), boxEdges (12),
  topBrackets (8), groundMark (8 bracket arms + a 2-segment centre cross). Camera-relative floats, theme tokens via
  `HoloTheme.argb`. Segments are collected into preallocated arrays (store 2048); `flush` keeps the nearest
  `MAX_SEGMENTS = 512` (quickselect on the midpoint distances, ties filled exactly) and emits them to a `Sink`.
- Ribbons (effects SUBTLE/FULL, no shader pack): one camera-facing quad per segment, half width scaled by each
  end's distance so the core holds `0.75 x GUI scale` screen pixels; FULL adds a 3x wide glow quad at half alpha.
  Render type `HoloRenderTypes.world()` ("utilitysuite_holo_world": position-tex-colour, atlas with linear
  filtering, translucent, `LEQUAL_DEPTH_TEST`, colour-only write, no cull, `ITEM_ENTITY_TARGET` output like vanilla
  lines, sorted on upload).
- Plain fallback: `EffectLevel.OFF` or an Iris/Oculus shader pack (`net.irisshaders.iris.api.v0.IrisApi
  .isShaderPackInUse()` by reflection, bound once to a `MethodHandle`, no per-frame allocation, false when absent):
  vanilla `RenderType.lines()` with the same palette.
- Dashes advance along the polyline direction at 1.5 blocks/s from `FrameClock.nowMs()`; static unless
  `Motion.FULL`.
- The pass (`HoloWorldKit.Pass`, registered in `MarksBootstrap`): `onBegin` at `EventPriority.HIGHEST` and `onEnd`
  at `LOWEST` on `RenderLevelStageEvent`, stage `AFTER_PARTICLES` (where Ghost Line always drew). Begin publishes the
  kit with `Visuals.useWorld(kit)` (not in Clean-Screen or without a level, so adopters get `null` and draw
  nothing); adopters draw at normal priority through `Services.visuals().world()`; end calls
  `Visuals.useWorld(null)` and, only if something was collected, gets one buffer, flushes, `endBatch` once. An idle
  frame touches no buffer.
- Ghost Line (`GhostLineModule` / `GhostLine`): no own buffers or `RenderType` any more. The path (rendered player
  position first) is drawn as a faint continuous base (`ACCENT` x 0.25) plus dashed polylines cut into fade bands
  (`GhostLine.band`), each band a whole number of dash periods so the dash pattern continues across bands; alpha
  fades from the opacity setting at the player to 30 % of it at the end. Jump mode: a ground mark at the landing in
  `ACCENT` / `WARN` / `DANGER` from `GhostLine.quality(lethal, landDamage, missDistance)` (miss > 0.5 block or
  lethal = DANGER; damage or a smaller miss = WARN). Route mode: the player-sized ghost outline (`boxEdges`,
  `LINE_STRONG`). Nothing drawn when the module is off, idle, or the kit is absent.

## Tests

- `SuiteFontsTest`: resolution with files absent / present / setting Vanilla / Force Unicode / failed load,
  generation bumps, generated definitions parse and name the files + the vanilla fallback, zero allocation in
  `resolve`.
- `HoloWorldKitTest`: quad/line counts per primitive, plain fallback, the 512 cap keeps the nearest (shuffled
  input, ties), store overflow counted, quickselect, dash coverage and advance, constant screen width, idle pass
  emits nothing, a whole frame (over the cap) allocates nothing against a no-op sink.
- `GhostLineTest` (kept green, extended): quality grades and tokens, band cutting, fade bands + quality mark through
  a recording `IHoloWorld`, route body, zero allocation in `draw`.
- `VisualSettingsTest`: 7 settings, new keys at 5 and 6, font/armed_marker defaults and round trip.
